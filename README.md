# 💊 Lembrete Popular

Site para consultar a próxima data de retirada de medicamentos pelo **Programa Farmácia Popular do Brasil**.

A ideia do projeto é facilitar o acompanhamento das retiradas, principalmente para quem acaba esquecendo a data e precisa saber quando poderá realizar uma nova retirada.

🔗 **Site:** https://lembrete-popular.vercel.app/

## Sobre

O Lembrete Popular permite informar a data da última retirada e calcular a próxima data prevista, levando em consideração as regras do programa.

Também possui opções para receber a informação por **SMS ou e-mail**, além de links para consultar os medicamentos disponíveis no programa e encontrar farmácias credenciadas.

## Funcionalidades

- 📅 Consulta da próxima data de retirada
- 📱 Envio da data por SMS
- 📧 Envio da data por e-mail
- 💊 Consulta do elenco de medicamentos
- 📍 Acesso à lista de farmácias credenciadas
- 📱 Layout adaptado para celular e computador

## Tecnologias

- HTML
- CSS
- JavaScript
- Vercel

## Como usar

Acesse o site:

🔗 https://lembrete-popular.vercel.app/

Informe a data da sua última retirada e faça a consulta. O sistema irá mostrar a próxima data prevista.

## Aviso

O Lembrete Popular é um projeto independente e serve apenas como uma ferramenta de auxílio para consulta.

A data exibida pelo sistema pode não representar a data efetivamente disponível para retirada. Em caso de dúvida, confirme as informações diretamente com uma farmácia credenciada ou pelos canais oficiais do Programa Farmácia Popular.
